## Considerações Técnicas

### Bibliotecas Necessárias
- **GSAP (GreenSock)**: Já instalado no projeto ✅
- **ScrollTrigger**: Plugin do GSAP para animações de scroll
- **Lenis**: Smooth scroll (opcional, mas recomendado)

### Performance
- Usar `will-change` CSS para otimizar animações
- Implementar `IntersectionObserver` para lazy loading de animações
- Testar em dispositivos móveis (animações podem ser pesadas)

### Acessibilidade
- Respeitar `prefers-reduced-motion` (já implementado no projeto ✅)
- Garantir que animações não atrapalhem leitores de tela
- Manter funcionalidade sem JavaScript

### Compatibilidade
- Testar em navegadores modernos (Chrome, Firefox, Safari, Edge)
- Fallbacks para navegadores antigos
- Progressive enhancement

## Exemplos de Código (Referência)

### Scroll Card com Barra de Progresso
```typescript
// Usar GSAP ScrollTrigger
import { gsap } from 'gsap';
import { ScrollTrigger } from 'gsap/ScrollTrigger';

gsap.registerPlugin(ScrollTrigger);

// Animar card com barra de progresso
gsap.to('.card-progress', {
  scaleX: 1,
  scrollTrigger: {
    trigger: '.card',
    start: 'top center',
    end: 'bottom center',
    scrub: true,
  }
});
```

### Mockup Scroll Zoom
```typescript
// Efeito de zoom ao scroll
gsap.to('.mockup-image', {
  scale: 1.2,
  scrollTrigger: {
    trigger: '.mockup-container',
    start: 'top bottom',
    end: 'bottom top',
    scrub: 1,
  }
});
```

### Interação Dinâmica (Tooltip que segue cursor)
```typescript
// Tooltip que segue o mouse
const tooltip = document.querySelector('.tooltip');

element.addEventListener('mousemove', (e) => {
  gsap.to(tooltip, {
    x: e.clientX,
    y: e.clientY,
    duration: 0.3,
    ease: 'power2.out'
  });
});
```
