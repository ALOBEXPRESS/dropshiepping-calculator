# Calculadora de Precificação Dropshipping Nacional

Aplicação React + TypeScript para precificação inteligente de produtos em dropshipping, integrando taxas de múltiplos marketplaces (Mercado Livre, Shopee, TikTok Shop, Enjoei), gestão de tráfego, anúncios, afiliados e sincronização Bling ERP.

## Funcionalidades Principais

- **Precificação Inteligente & Multi-Marketplace**: Cálculo automático de margens, markup, taxas de comissão, custos fixos e fretes por marketplace.
- **Integração Bling ERP**: Sincronização em tempo real de produtos, variações, pedidos e estoque.
- **Analytics & Dashboard Interativo**: KPIs consolidados, gráficos de conversão e distribuição de leads com animações fluidas.
- **Gestão de Campanhas & Tráfego**: Simulação e rateio de custos de tráfego pago (Shopee Ads, Mercado Ads, TikTok Ads) e parcerias orgânicas (influenciadores e afiliados).
- **Interface Otimizada & Responsiva**: Design moderno em dark mode com tokens consistentes, microinterações e alta performance.

## Instalação e Execução

1. **Instalar dependências**:
   ```bash
   pnpm install
   ```

2. **Configurar variáveis de ambiente**:
   - Copie o arquivo `.env.example` para `.env`
   - Preencha com as credenciais necessárias (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, etc.)

3. **Executar em desenvolvimento**:
   ```bash
   pnpm run dev
   ```

4. **Executar testes**:
   ```bash
   pnpm test
   ```

5. **Build de produção**:
   ```bash
   pnpm run build
   ```
