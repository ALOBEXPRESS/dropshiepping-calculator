## Como Usar

1. Navegue até a pasta da categoria desejada
2. Leia os arquivos relevantes para sua necessidade
3. Consulte os índices para encontrar documentação específica

## Convenções

- Arquivos com prefixo numérico (ex: `00_`, `11_`) indicam ordem de leitura
- Arquivos com `RESUMO_` contêm resumos de sessões ou features
- Arquivos com `GUIA_` são tutoriais passo a passo
- Arquivos com `CORRECAO_` documentam fixes aplicados
- Arquivos com `IMPLEMENTACAO_` documentam novas features
