# Guia de Deploy (Vercel)

Este projeto foi preparado para ser implantado na Vercel. Siga os passos abaixo:

## 1. Pré-requisitos
- Conta na [Vercel](https://vercel.com/)
- Repositório no GitHub (ou GitLab/Bitbucket)

## 2. Configuração do Projeto na Vercel
1. Importe o projeto do GitHub na Vercel.
2. Na tela de configuração ("Configure Project"):
   - **Framework Preset**: Vite
   - **Root Directory**: `./` (padrão)
   - **Build Command**: `npm run build` (ou `vite build`)
   - **Output Directory**: `dist`

## 3. Variáveis de Ambiente
Você **PRECISA** configurar as variáveis de ambiente na Vercel para que a aplicação funcione.
Vá em **Settings > Environment Variables** e adicione:

| Key | Value |
|-----|-------|
| `VITE_SUPABASE_URL` | `sua url do projeto supabase` |
| `VITE_SUPABASE_ANON_KEY` | `sua-chave-anonima-aqui` |

*Nota: Você pode encontrar a chave anônima no arquivo `.env` local ou no painel do Supabase.*

## 4. Segurança
As regras de segurança (RLS) do Supabase devem estar ativas.
Certifique-se de que todas as tabelas sensíveis tenham RLS habilitado e políticas configuradas.

## 5. Deploy
Clique em "Deploy". A Vercel irá construir e publicar sua aplicação.
